    - `ring_frame(atoms, ring_indices)`: atoms = sequence of (x, y, z); validate len(ring_indices) >= 3 (ValueError 'ring needs >= 3 atoms'). Centroid = mean of the selected atoms. Normal = Newell's method over the selected atoms IN THE GIVEN INDEX ORDER (order-stable, no degenerate cross products): n_x = sum((p.y - q.y)*(p.z + q.z)), n_y = sum((p.z - q.z)*(p.x + q.x)), n_z = sum((p.x - q.x)*(p.y + q.y)) over consecutive pairs (p, q = pts[i], pts[(i+1) % k]). |n| < 1e-8 -> ValueError('degenerate ring (normal length %.3e)' ...). Unit-normalize. Planarity: max |dot(p - c, n)| over ring atoms; > 0.15 -> ValueError('non-planar ring (max deviation %.3f A)' ...). Reference axis: unit(centroid -> FIRST ring atom) orthogonalized against the normal (r = v - dot(v, n)*n, unit-normalize; if the orthogonalized length < 1e-8 -> ValueError 'degenerate ring reference axis'). Return (centroid, normal_unit, ref_unit).
    - `place_pickup(pickup_atoms, pickup_ring_indices, tail_centroid, tail_normal, tail_ref, distance_a, lateral_offset_a, lateral_along_ref=True)` -> (placed_atoms, R, t):
      * (c_pick, n_pick, p1) = ring_frame(pickup_atoms, pickup_ring_indices); p2 = cross(n_pick, p1).
      * Tail basis: n_t = unit(tail_normal); r1 = unit(tail_ref orthogonalized against n_t); r2 = cross(n_t, r1). (Right-handed (r1, r2, n_t): r1 x r2 = n_t.)
      * R = B_tail . B_pick^T where B stores basis vectors as columns: R[i][j] = r1[i]*p1[j] + r2[i]*p2[j] + n_t[i]*n_pick[j]. (Maps world vectors from the pickup frame to the tail frame; identity when frames coincide.)
      * target = tail_centroid + n_t*distance_a + (lateral_offset_a * r1 if lateral_along_ref else lateral_offset_a * r2).
      * placed[i] = R.(p_i - c_pick) + target; return (placed, R, t) with t = target - R.c_pick (so placed = R.p + t). R returned as a 3-tuple of 3-tuples (row-major); R and t are what the Phase-5 connector feeds cmd.transform_selection (matrix layout convention to be verified in Phase 5 — noted in docstring).
      * Docstring notes: normal sign preserved (stacking 'above' vs 'below' is the caller's sign choice on tail_normal); azimuth = 0 aligns the pickup's reference axis with the tail's projected reference axis — this is what makes the eclipsed dimer2 reproducible.

Inclusive boundaries: a coord exactly equal to box_min[k]/box_max[k] does NOT violate.
      * Atom test: for i in placed (ascending), j in existing (ascending): d = euclidean distance; d < threshold_a -> {'kind': 'atom', 'pair': (i, j), 'distance': d} — return the first violation.
      * Clear -> None. box_min/box_max are 3-tuples (the game's z-extent is display-only but the gate checks all three axes).
