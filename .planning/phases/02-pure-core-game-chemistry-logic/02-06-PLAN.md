- **Constants (module-level, documented):** SPEED_A_PER_S = 3.0 (GAME-08; exact value = Phase-4 playtesting) and the DIRS map: {'left': (-1.0, 0.0), 'right': (1.0, 0.0), 'up': (0.0, 1.0), 'down': (0.0, -1.0)}. No other constants in this plan.
- **Coordinate model:** continuous 2D floats in the box's xy-plane; z is display-only and carried but never rotated. Directions are the 4 axis names mapping to the DIRS unit vectors. Heading angles (math convention, CCW positive): right=0, up=+90, left=180, down=-90. Heading is stored as a unit VECTOR (not a name).
- **Segment list order (STATE ONLY — no collision semantics here):** index 0 = OLDEST (tail-most), LAST = most recently stacked (nearest the head); new stacks APPEND at the end. Segment records: `{'molecule_id': str, 'centroid': (x, y), 'atoms': [(sym, x, y, z), ...], 'atoms_n': int}`. The `segments` constructor/reset parameter is an explicit TEST SEAM (production chains grow via 02-10's attach_segment). The engine copies segment dicts (never mutates caller data).
- **step(dt) contract:** paused -> return [] immediately. Otherwise: head += heading * SPEED_A_PER_S * dt; emit [('moved', (x, y))] with the NEW position. A pending direction is intentionally NOT consumed and produces NO event — the queue only buffers; 02-13 adds turn application at step start. Test-suite consequence (forward compatibility): 02-06's tests NEVER call step() while pending is non-empty, so 02-13's later change cannot break them.
- **request_direction(d):** invalid name -> ValueError. Reference = CURRENT heading (02-13 changes the reference to the sweep target while sweeping). dot(d_unit, heading) < -0.5 -> ignored, return False (180, locked); dot > 0.5 -> ignored, return False (same direction); len(pending) >= 1 -> ignored, return False (buffer full, "max 1 buffered beyond current"); else buffer and return True.
- **Constructor:** GameEngine(head=(0.0, 0.0), heading='right', segments=None). head/heading seed the state (heading resolved through DIRS); segments is the test seam above. State: head, heading, segments (copied), pending (max-1 buffer of direction names), paused. 02-10 EXTENDS this signature with keyword args (box_min/box_max/pickups/cap/atom_budget) — keep it keyword-friendly so that extension is additive.
- **pause()/resume():** paused flag flips; paused step() returns [] and mutates nothing. **reset(...):** same parameters as __init__; rebuilds ALL state (GAME-07 restart).
- **Determinism:** pure float math, NO RNG, NO wall-clock (pause timing is the GUI's job — Pitfall 9.3).
- **Hard conventions:** Python 3.6 syntax only (%-formatting, no dataclasses/walrus/f-string `=`); stdlib math/collections only; purity auto-classifies PURE (no pymol/Qt/numpy anywhere, function bodies included); zero sys.modules stubs.
