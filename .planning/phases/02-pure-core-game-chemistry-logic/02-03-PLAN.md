Elements/coords length mismatch or coords rows not 3-long -> XyzError.
- `write_xyz_file(path, elements, coords, comment='')` — writes text with encoding='utf-8'.
- `read_xyz_text(text)` -> (comment, [(symbol, x, y, z)]): splitlines; line 1 stripped must parse as int > 0 (else XyzError 'line 1: atom count'); at least 2 lines required; comment = lines[1]; then collect atom rows from the remaining lines IGNORING empty lines: exactly count rows must follow (fewer -> XyzError naming expected vs found; any extra NON-EMPTY line after the count rows -> XyzError); each row >= 4 whitespace tokens; symbol = token[0] must be in ELEMENT_SYMBOLS (else XyzError naming the symbol and line number — bad.xyz's 'Xx' case); coords = float(token[1]), float(token[2]), float(token[3]) (non-float -> XyzError with line number).
- `read_xyz(path)` — open(path, encoding='utf-8'), delegate to read_xyz_text.
