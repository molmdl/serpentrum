Pinned design (research R7 — implement EXACTLY this):
- `SCHEMA_VERSION = 1`
- `DEFAULTS = {'schema_version': 1, 'demo_set': 'set_a', 'head_molecule': 'random', 'box_preset': 'medium', 'xtb_path': None, 'win_cap_molecules': 10, 'atom_budget': 100, 'broadening_fwhm': 16.0, 'speed': 3.0}` (SETUP-04 default 'random'; ~10 mol / ~100 atoms is the PROJECT-approved safe default; broadening 10-20 cm^-1 typical per STACK.md §6; speed mirrors game_engine's SPEED_A_PER_S = 3.0).
- `BOX_PRESETS = {'small': ((-12.0, -12.0), (12.0, 12.0)), 'medium': ((-18.0, -18.0), (18.0, 18.0)), 'large': ((-25.0, -25.0), (25.0, 25.0))}` — xy extents in Angstrom; z-depth is display-only (bridge concern, Phase 4/5).
- `validate(setup)` -> (errors: [str], warnings: [str]):
  - ERRORS: `schema_version` != 1; `demo_set` not in KNOWN_SETS = ('set_a',) (v1 ships Set A only — locked decision); `box_preset` not in BOX_PRESETS; `win_cap_molecules` < 1 or > 20 (hard max); `atom_budget` < 1; `xtb_path` set (not None) but invalid — non-empty str, exists, is a file, no quote chars (local `_xtb_path_problems(path)` helper returning problem strings; SAME rules as xtbenv.validate_binary_path — kept local with a "keep in sync with serpentrum/xtbenv.py" comment because xtbenv is a PARALLEL wave-1 plan and may not exist in your worktree; a later wave may unify); `speed` not a number > 0; `broadening_fwhm` not a number > 0; `head_molecule` not a non-empty str. Use the py3.6-safe number check (numbers are int/float but NOT bool).
  - WARNINGS: `win_cap_molecules` > 10 OR `atom_budget` > 100 -> exactly this message: `'hessian cost scales ~N^3; a ~100-atom snake may take 30-90 s'` (rationale: PITFALLS 2 measured 13 atoms 0.28 s / 26 atoms 1.03 s hessian wall; N^3 extrapolation). The actual pre-xtb re-check is Phase 6's runner (SPECTRA-06's runtime half).
- `save_setup(setup)` -> text: validate first; errors -> SetupError listing them; else `json.dumps(setup, sort_keys=True, indent=2)`.
- `load_setup(text)` -> dict: json.loads wrapped (any ValueError/JSONDecodeError -> SetupError 'setup text is not valid JSON: <msg>'); must be a dict; `schema_version` != 1 -> SetupError('setup schema_version %s not supported (this build reads version %d)'). v1 does NOT validate the loaded dict beyond schema_version (full validation is the caller's validate() call).
- `randomize_head(candidates, seed)` -> `random.Random(seed).choice(candidates)`; empty candidates -> SetupError('no head molecule candidates'). NEVER the global random module (determinism + reproducibility on the same 3.6 build). candidates = validated molecule ids.
- `new_setup()` -> `dict(DEFAULTS)` (copy — callers mutate freely; nested values are all scalars/None so a shallow copy suffices).
- **Hard conventions:** Python 3.6 (%-formatting, no dataclasses/walrus/f-string `=`); stdlib json/math/random only; purity auto-classifies PURE; zero sys.modules stubs; do NOT import other Phase-2 modules (xtbenv is parallel — hence the local path-rule helper).
- **Test conventions:** discovery = `python3.6 -m unittest discover -s tests -p "test_*.py" -v` (never `-t .`); tests/ has NO `__init__.py`; sys.path self-insert preamble; tmpdir files cleaned with shutil.rmtree in addCleanup.
