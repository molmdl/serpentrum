Grammar (research §1.2, byte-verified — implement exactly):
1. Split with `text.splitlines()` (neutralizes CRLF + missing trailing newline). Open files with `encoding='utf-8'` (the header contains the UTF-8 char U+207B/U+00B9 in `km*mol⁻¹`).
2. Line 1 stripped MUST equal `'$vibrational spectrum'` — else `SpectraParseError('vibspectrum header', 1, line)`.
3. The final non-blank line stripped MUST equal `'$end'` — else `SpectraParseError` whose message contains `'$end'` and the offending line number.
4. Lines whose stripped form starts with `'#'` are comments — skip them (the real fixture uses 2 such header lines; the synthetic CO2 fixture in Task 2 adds more).
5. Every other non-blank line is a data row: `t = line.split()`. `len(t) == 4` → trivial row `[mode, freq, intensity, '-']`; `len(t) == 5` → real row `[mode, symmetry, freq, intensity, selection]`. Uniform field indexing per research: `mode = int(t[0])` (the file's own 1-based numbering, trivial rows included), `freq = float(t[-3])`, `intensity = float(t[-2])`, `selection = t[-1]` (real rows), `symmetry = t[1] if len(t) == 5 else ''`. Any other token count → `SpectraParseError('vibspectrum row', lineno, line[:80])`. Non-numeric mode/freq/intensity (e.g. `******`, `abc`) → `SpectraParseError('vibspectrum numeric field', lineno, line[:80])` — wrap the float()/int() conversions; a raw ValueError escaping is a bug.
6. Return `Spectrum(n_atoms=0, atoms=[], modes=[...])` — modes in file order, each `Mode(index=mode, freq=freq, intensity=intensity, vectors=())` (empty tuple, per the 02-01 Mode contract: vibspectrum carries no displacement vectors). `n_atoms=0` is intentional and documented: vibspectrum has no geometry block; consumers take N from the g98 parse or the .xyz.
