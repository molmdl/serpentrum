**Grid-scan spawn fallback now starts at a seeded `randrange(cell_count)` cell and wraps (identical full coverage), so forced fallbacks on saturated boxes spread per seed instead of always landing at the most-negative-corner-first legal cell — deterministic per seed, GAME-07 stream shape untouched.**

## Accomplishments

- `_grid_scan(record, atoms, head_xy, chain_atoms, live_centroids)` factored from `_spawn`'s inline while-loop scan; the fallback branch is now a single delegation call.
- Seeded start cell: one `self._rng.randrange(cell_count)` consumed **only** when the fallback fires; `idx = (start + i) % cell_count` wrap iteration checks every cell exactly once — coverage identical to the pre-5.3-02 scan, so `None` is returned only when genuinely no legal cell exists (TestExhaustion's ±6 saturation and (0,0)-(2,2) pins green UNMODIFIED).
- Corner-bias clustering killed: two different seeds forced into the fallback land at DIFFERENT legal cells (pinned: seed 4242 → cell (24.5, 22.5), seed 163 → cell (24.5, 24.5)); the same seed reproduces byte-identically.
- Degenerate-box hard guard: `nx <= 0 or ny <= 0` returns None BEFORE any randrange — guarded on the axis counts, since `cell_count = nx*ny` is +1 for the (0,0)-(2,2) test box and a cell_count-only guard would not intercept.

## Decisions Made

- **Seed pair 4242/163 for the RED driver** (rationale): the plan's draft pair 4242/777 happened to agree under the seeded start — both reach legal cell idx 892 = (24.5, 22.5) (125/4000 probed starts diverge to idx 924, so agreement is the ~97% common case). Write-time probe (standalone script, seed-independent legal-cell enumeration + simulated GREEN draw streams) confirmed seeds 4242 and 163 BOTH exhaust the 32-draw loop (no lucky uniform draw — critical: a lucky draw would make the test pass for the wrong reason) and diverge under the seeded start: 4242 → (24.5, 22.5), 163 → (24.5, 24.5). Choice recorded in the test comment per the plan's sanction; deterministic thereafter.
- **Pocket lattice downscaled to the ±35 preset** (rationale): plan's explicit cost note — the full ±55 cover lattice is ~2,680 atoms and forces a ~43M-op fallback crawl per drive. The ±35 lattice (1,068 atoms, 32×32 = 1,024 cells) keeps exactly two legal fallback cells ((24.5, 22.5) idx 892 and (24.5, 24.5) idx 924, write-time probed), which is precise enough to discriminate scan-start variants.
- **Guard on axis counts, not cell_count** (rationale): for the (0,0)-(2,2) degenerate box the shrunk span is negative, giving nx = ny = −1 but cell_count = nx*ny = +1 — a cell_count-only guard would NOT intercept and `randrange` would fire with a bogus grid. `test_too_small_box_returns_none` stays green UNMODIFIED.
