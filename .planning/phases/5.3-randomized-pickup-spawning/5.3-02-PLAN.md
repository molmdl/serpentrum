<objective>
Make the grid-scan fallback's start cell seeded so a forced fallback (saturated pockets late-game) can no longer always land at the same most-negative corner cell.

Purpose: under 5.3-01's uniform policy the fallback fires far less often than today, but when it DOES fire (genuinely saturated small boxes), the current x-major scan from `(x0, y0)` would repeatedly spawn the new molecule at the same corner — a new "too predictable" complaint in miniature. Research spawn-policy.md flags this as cheap refinement #2. The scan stays fully deterministic per seed (GAME-07) and keeps complete coverage (None only when truly nothing is legal).

Output: `_grid_scan` helper with a seeded start index + wrap iteration in `serpentrum/spawn.py`, plus forced-fallback pins in a new `TestFallbackOffset` class. TDD: RED -> GREEN -> (REFACTOR), 2-3 atomic commits.
</objective>
