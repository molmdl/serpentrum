## Accomplishments

- **SC3 — specific generic skip reason:** `_REASON_TEXT[placement.SKIP_GENERIC_NO_RING] = 'no aromatic ring for generic pi-stack'`, rendered by `reason_text`/`skip_text` and auto-labeled `'skipped Nx'` by the recap prefix (`startswith('SKIP_')` — no recall change needed, pinned anyway). Unreachable when consent is OFF (placement guard never emits the code).
- **SC2 labeling half — consent-aware mode note:** `stack_mode_note(records, consent=False)`. OFF (omitted or False) output is byte-identical for ALL inputs — the C1 literal and the None matrix; every pre-existing pin (C1 wording, skip literals, recap taxonomy, one-shot call-site scan) stayed green UNTOUCHED. Consent ON: the private `_any_stackable` predicate also counts records carrying `stack_ring` (fixing the false-positive demonstration-mode note for ring-bearing upload-only pools), and a zero-stackable consent-ON pool gets the DRAFT variant `'no molecule has a planar aromatic 6-ring for generic pi-stack - demonstration mode: ...'` so the note never claims "no stacking entries" falsely.
- **SC2 labeling half — consent disclosure:** `generic_consent_note(consent)` returns the DRAFT ASCII line `'generic pi-stack enabled: illustrative geometry - user-approved [Janiak 2000]'` when truthy, None for False/0/None — the stack_mode_note None-contract, NOT speed_note's always-line contract, so OFF runs gain ZERO log lines and the once-per-run log order stays byte-identical. Caller gating belongs to plan 5.2-06.
- **One C1/C2 wording source (EQ-setup-3 + EQ-setup-6):** plan 5.2-05's Setup-side Apply soft warning will reuse `stack_mode_note(records, consent)` directly, guaranteeing the Apply-time warning and the begin_game note can never contradict; the setup-research's separate DRAFT C2 text is dropped. The known dataset-unavailable-Apply edge is documented in the stack_mode_note docstring (Apply-time warning covers it; the note does not re-detect).
