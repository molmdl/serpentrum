# serpentrum - Classical snake game in (bio-) molecular viewer stacking molecules,  as an analogue of "self-assembly and spectra calculation".

## Aim

Develop a pymol plugin of an educational snake game as an analogue of "self-assembly and spectra calculation".
Depends on research, can design in a 2D plane or 3D.
For students and educators who want an engaging way to explore and study molecular interactions.

---

## Requirements of the pymol plugin

0. the user install the plugin as a standard PyMOL plugin. For development and testing I prefer install by adding to plugin path.
1. starting the pymol plugin from manual, a setup window will popup with 3 tabs: setup, gamplay, and spectra.
2. the setup tab in the popup window allow the user to change the following parameters:
   * Dropdown to choose which demo set to use (see note 1), or upload a set of small molecules matching the molecular size requirement.
   * Dropdosn to choose which preset box size to use
   * The molecule in the set to select as the 1st molecule of the snake, has an option to choose random (default).
   * Path to xtb and the resource available for xtb env setup (default auto detect)
   * Length of snake to cap for winning the game (also set cap by number of atoms and resource available)
3. the bottom of the popup within would have 7 buttons: (1) Reset, (2) Randomize, (3) Save Setup, (4) Load Setup, (5) Generate and export, (6) Cleanup model (7) Start 
   3.1. Reset: restore the default settings
   3.2. Randomize: randomize setup
   3.3. Save Setup: save the game setup parameters to a file
   3.4. Load Setup: load the setup parameters from a file
   3.5. Cleanup: clear generated by the game that is not in the original object 
   3.6. Start: Start the game  
4. Once the user are happy with the game setup, they click "Start"
5. Clicking start do the following:
   * jump to the Game status tab of the same window
   * countdown 3, 2, 1, then start the game
6. the Game status tab shoud have the following:
   * a generic rolling info box
   * timing after the game started, and the number of molecule remains before winning (out of info box)
   * a pause button to pause mid-game, which change to resume after pausing, and back to pause after resuming
   * restart button to restart the game from the initial state
7. Gameplay:
   7.0. In the OpenGL viewer: the box bounary is clearly displayed. each game start with the chosen "head" in sphere representation, and one or more randomly placed small molecule in stick representation.
   7.1. The chosen molecule "head" start moving in the viewer, the player user the arrow key to change direction and try to pick up the small molecule.
   7.2. Consequence of behaviors:
         a. succefully picking a small molecule stack it to the snake and add the molecule count + atom count (hidden, for double-checking the cap before xtb)
         b. hitting boundary or the snake = game over, the snake is consider "complete"
         c. a player win the game if the length of the snake is over a molecule count.
   7.3. After the snake is "complete", clear the OpenGL window and focus on the completed snake. In the game status info box calculate and show the length of the snake  and total score til the stage, and activate the button "get spectra".
   7.4. Pressing the "Get Spectra" button jump to the Spectra tab 
         a. this tab has option for xtb optimization + calculation of the final snake amd plotting.
         b. The "Spectra" tab allow setup for xtb (minimal, with default), button to start calculation and log to show progress, panel to plot the spectra and allow minimal adjust of the plot (e.g. size and labels), button to save the plot. 
         c. This table also  shows a table of frequency that clicking it show the vector on the snake in openGL window (for vibrational spectrum). For v1, no need for animation to make it simple.
   7.5. Going back to setup tab allow restarting from beginning


Note 1: Provide several options for demo. Demo SDF/mol2 should be pre-download citing the source in a doc, with the set of molecules known to stack and with know intermolecular distances from a database.
